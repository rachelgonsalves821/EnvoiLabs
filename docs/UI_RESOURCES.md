# UI resource registry

Use this registry for every Envoi Labs UI task, including internal admin screens, respondent flows, researcher screens and shared components.

1. Read the [Envoi Labs design system](design-system/README.md) and the relevant component spec. Keep its tokens, accessibility requirements and copy rules.
2. Read the [Frontend Design skill](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md) and consult any additional entries below that match the task. Use external examples as inspiration for original work.
3. Record which resources you used and the resulting design decision in the PR. Include relevant viewport, keyboard, motion or performance checks.

| Resource | Apply it to |
| --- | --- |
| [Scrolltide](https://www.scrolltide.co/) | 3D, shaders and scroll-driven motion. Use it for the Echo or other approved motion work, with a reduced-motion and static fallback where required. |
| [Dribbble web design](https://dribbble.com/shots/popular/web-design) | Visual exploration for composition, hierarchy and interaction patterns. |
| [Anthropic Frontend Design](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md) | Visual direction and frontend craft for every UI task. |
| [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) | UI patterns, page structure, forms and dashboard interaction. |
| [Emil Kowalski's skills](https://github.com/emilkowalski/skills) | Motion timing, transitions and interaction feedback. |
| [Impeccable](https://github.com/pbakaus/impeccable) | Design critique and polish before a UI PR. |
| [ibelick UI Skills](https://github.com/ibelick/ui-skills) | Component implementation and UI review, especially interaction and accessibility. |
| [Anthropic Skills](https://github.com/anthropics/skills) | Upstream collection for Frontend Design and other relevant skills. |
| [Vercel Agent Skills](https://github.com/vercel-labs/agent-skills) | React and Next.js implementation, performance review and web-interface guidelines. |

Read upstream guidance as reference material. Scripts, packages and assets from these sources follow the repo's existing dependency review process.
